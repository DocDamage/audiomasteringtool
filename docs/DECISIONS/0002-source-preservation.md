# ADR 0002: Source preservation over mandatory stem reconstruction

Status: Accepted

## Decision

The original stereo source is canonical. Stem separation may produce analysis masks/control signals without replacing the source. Reconstructed stems are used only when expected audible repair benefit exceeds artifact risk.

## Why

Automatic separation can introduce phasing, musical-noise, transient, and stereo-image artifacts. Instrument-aware mastering does not justify damaging a clean source.
