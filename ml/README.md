# Instrument-model research workspace

This directory holds reproducible manifests, evaluation outputs, calibration records, and export metadata. Do not commit copyrighted training audio or unreviewed model weights.

Production promotion requires a frozen evaluation manifest, per-class metrics, unknown-rejection results, a calibration record, and a completed legal/security review recorded in the instrument model manifest.

The selected Phase 6 production data/model route is documented in
[`instruments/PRODUCTION_DATA_AND_MODEL_PLAN.md`](instruments/PRODUCTION_DATA_AND_MODEL_PLAN.md).
